# Лабораторна робота: Git та GitHub Pages

Цей репозиторій містить лабораторну роботу з системи контролю версій Git та публікації сайту через GitHub Pages.

## Структура сайту

- **index.html** — головна сторінка з інформацією про автора.
- **variant.html** — сторінка з виконаним завданням за варіантом.
- **team.html** — сторінка для учасників команди.
- Додаткові сторінки (за потребою) можна додавати в корінь репозиторію.
